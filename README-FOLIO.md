This repository is forked from https://github.com/eXtensibleCatalog/NCIP2-Toolkit just to simplify our deployment of these dependency artifacts to our local maven repository, for use by mod-ncip.

This fork is limited to the upstream core/trunk directory: https://github.com/eXtensibleCatalog/NCIP2-Toolkit/tree/master/core/trunk
In our fork that directory has been moved to our root directory.

These upstream sub-directories have been deleted in our fork because we don't use them:
* core/trunk/responder
* core/trunk/dummy
* core/trunk/examples
